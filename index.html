If a value is missing or invalid, the message under the preview tells you what to fix. Only fields used by the selected template are required.

        


        

          
Edit templates

          
Select Edit templates to add, duplicate, rename, or remove a template. Change the message in the template editor and use the Insert buttons to add fields. Select Save changes when you are finished.

          
The package name is only added when the message contains {package}.

          
{tv} adds the selected TV package name. When a message contains {tv1} or {tv2}, set its matching text for every package under TV text by package.

        


        

          
Template fields

          

            
{services}
Combines the choices selected under Included services.

            
{broadband}
Adds the selected broadband option.

            
{broadband_price}
Adds the broadband price and currency.

            
{tv}
Adds the selected TV package name.

            
{streaming}
Adds the selected streaming option.

            
{package}
Adds the package name saved with the template.

            
{price}
Adds the main price and currency.

            
{broadband2}
Adds the saved broadband campaign text.

            
{tv1}
Adds the TV offer text saved for the selected package.

            
{tv2}
Adds the TV campaign text saved for the selected package.

            
{date}
Adds today's date, or the date entered in the form.

            
{date+N}
Adds a date after the chosen date. Replace N with any number of days, such as {date+14}.

            
{date-N}
Adds a date before the chosen date.

          

          
Enter dates as DD/MM/YYYY.

        


        

          
Saving and moving settings

          
Template settings are saved in this browser on this device. They remain available when you close and reopen the page. Clearing this site's browser data removes them.

          
Use Export to download a JSON backup. Use Import to load that file in another browser or on another device. Importing replaces the current browser settings, so export a backup first if you want to keep them.
